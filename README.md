# متصفح آمن — Secure Browser (الإصدار الإنتاجي 1.6.0)

متصفح Android احترافي **قابل للاستخدام اليومي** مبني على **Chromium (System WebView)** مع:

- **قائمة بيضاء مفعّلة دائمًا** — لا يمكن إيقافها من أي إعداد أو مسار.
- **طبقة أمان مركزية (fail-closed)** — كل تنقل/تنزيل/تطبيق خارجي يمر عبرها.
- **لوحة والدين كاملة** محمية برمز (PBKDF2 + حماية brute force + قفل تلقائي).
- **وصول مؤقت** بنافذة زمنية (5/10/15/30/60/مخصص) يعود بعدها فرض القائمة تلقائيًا.
- **مدير تنزيلات حقيقي** بتقدم/سرعة/إيقاف/استئناف/موافقات وسياسة أنواع ملفات.
- **تطبيقات خارجية** (Telegram/WhatsApp/YouTube/Maps/Mail/Phone/SMS) عبر بوابة سياسة.
- **تاريخ + نشاط محظور + خط زمني موحّد** — حماية السجل من المستخدم العادي.
- تبويبات بمعاينات + استعادة جلسة + بحث داخل الصفحة + ملء شاشة غامر + تكبير + مشاركة + رفع ملفات.
- عربي/إنجليزي + RTL/LTR + Dark Mode + شاشات حظر وخطأ أصلية.

## 3. الضمانات الأمنية (ما لا يمكن كسره من الواجهة)

1. **القائمة البيضاء دائمًا:** `WhiteListEngine` بلا أي مفتاح إعداد لإيقافه؛
   `SecurityEngine` هو المنفذ الوحيد لكل تنقل (روابط/توجيهات/JS/popups/عناوين/سجل).
2. **الوصول المؤقت:** نافذة يفتحها الوالد بعد الرمز؛ انتهاؤها مخزن مشفرًا —
   إغلاق التطبيق لا يحولها لتجاوز دائم؛ حتى أثناءها تبقى المخططات الخطرة محظورة.
3. **السجل:** التسجيل بنيوي (لا مفتاح تعطيل)؛ المسح/الحذف داخل لوحة الوالدين فقط.
4. **التنزيلات:** كل تنزيل → `DownloadPolicy` (المصدر مسموح؟ المخطط ويب؟ النوع؟)
   — APK/EXE محظورة افتراضيًا، الأرشيفات والغير معروف ينتظر موافقة الوالدين.
5. **التطبيقات الخارجية:** إعداد والدين + كشف التثبيت + تأكيد صريح؛
   روابط التطبيقات (t.me/wa.me/youtu.be/Maps) إذا حظرتها القائمة → "فتح في التطبيق"
   بدل تجاوزها؛ `intent:` يُحكم على وجهته الاحتياطية عبر القائمة كاملة.
6. **التخزين:** PBKDF2-SHA256 للرمز (310k دورة)، AES-256-GCM بمفتاح Keystore لكل شيء حساس،
   بلا أسرار في الكود/السجلات/التفضيلات المكشوفة.

## 4. تدفقات المواصفة المطبقة

- **§7 إضافة موقع:** الوالدين → Add Website → Temporary Access → مدة → زيارة المواقع
  → History → "Add to WhiteList" → "ما الذي تريد السماح به؟" (3 خيارات) → حفظ → تنبيه
  "تمت الإضافة". انتهاء المؤقت = فرض تلقائي بلا تدخل.
- **§8 المؤشر:** شريط أصفر داخل المتصفح "وصول مؤقت — MM:SS" + إنهاء الآن؛
  التمديد من لوحة الوالدين فقط (إعادة مصادقة).
- **§30 الخطأ:** شاشة أصلية "تعذر تحميل الصفحة" + سبب مبسط + Retry/Back/Details
  (بلا رسائل WebView تقنية).
